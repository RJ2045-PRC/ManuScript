## 导图、正文编辑与结构阅读

重启 DSH 后首次打开 ManuScript 会进入项目库并播放「收笔稍驻」。在同一窗口切到会话或其他面板，再点 ManuScript，会回到离开时的项目库、正文或导图。想换项目时点「‹ 项目库」。

打开项目默认进入「正文编辑」。顶部可随时切换「导图」「正文编辑」「结构阅读」。全文工具栏左端是目录和章节路径，点击路径中的标题可以切换同级章节或展开子章节。点击「回到刚才」可恢复跳转前的位置。右端的笔／书按钮切换编辑和阅读，从「更多 → 源码模式」切换源码。

在「导图」从「新增 → 新增小标题」搭文章框架。选中节点时，Tab 添加子级，Enter 添加同级，两项也可在「新增」中点击。双击、空格或 F2 在节点内编辑标题，Enter 或 Tab 保存，Esc 取消。保存完成后，新按一次快捷键才继续新增。在 DSH 点章节会选中节点。行首写 `>` 可在所属节点内显示斜体写作备注。从节点「⋯ → 定位正文」跳到全文中的该节。点顶部「正文编辑」回到离开时的阅读位置。正文右上角可在编辑与阅读之间原地切换。在「项目工具 → 切换动效」选择详细、减弱或关闭，初次使用为减弱。

导图工具栏的「编辑」提供改名、上移、下移、移动章节、删除和撤销。也可把标题拖到目标的上缘、下缘或中部，将整节内容和子节放到目标之前、之后或内部。「只删除标题」保留本节内容并将子标题提升一级，「删除整节…」在确认后移除整个分支。「视图」集中缩放、适应画布、展开层级和颜色说明。独立构思卡可通过「关联正文小标题」挂到相应章节。

Markdown 中的 `>` 随正文进入 Draft 和导出文件。旧版单独保存的备注仍可在导图节点查看。导出含有旧版独立备注的稿件时可勾选「包含旧版章节备注」。

在「正文编辑 → 更多 → Markdown 配色与快捷键」可选择分色、素色，或四套随 DSH 亮暗模式切换的 Obsidian 风格配色（Minimal、Catppuccin、Gruvbox、Rosé Pine），也可下载或导入[配色 CSS 样板](../examples/Markdown-写作配色.css)，并点按快捷键改键。样板中的 :root 为通用配色，.theme-dark 覆盖深色颜色；也支持 .theme-light 和常用 Obsidian 颜色变量的直接色值。编辑、源码和阅读共用配色；快捷键只在正文输入时生效。Mac 用 ⌘，Windows/Linux 用 Ctrl：B 加粗，I 斜体，Shift+I 粗斜体，Alt+1…6 设置标题，Alt+0 还原普通段落。偏好保存在本机，不进入稿件、Word 或 PDF。

### 正文备份与恢复

在包含此功能的 DSH 插件中，为项目绑定本地文件夹。每次保存有变化的正文，ManuScript 会在该文件夹的 `正文备份/ManuScript-<项目ID>/` 下留一个只读版本。按目录名中的版本号找到最新一版，打开里面的 `manuscript.md`。LaTeX 稿使用 `manuscript.tex`。正文引用的项目图片和书目随版本目录保存。出现「备份待补」时，上次已完成的备份仍可打开。文件夹重新可用后，可从「正文编辑 → 更多 → 正文备份与恢复」重试。版本目录随改稿累积，由作者管理磁盘空间。

在同一菜单可「保存可编辑副本」。有图片或书目时，先解压下载的 ZIP，再编辑其中的正文。DSH 打不开时，直接从文件管理器找到备份，用编辑器「另存为」到其他目录后继续写；所需的 `figures/` 和 `references.bib` 可以一起带走。回到 ManuScript 后，在同一菜单选择「导入外部修改」，查看差异并确认采用。如果另一窗口刚保存过正文，刷新差异后再决定。完整的导图、批注和 Draft 历史可以通过项目 ZIP 备份。

### 正文引文与图片

在 Markdown 正文里，点引文左半边可在引文前续写，点右半边可在后面续写。右键选「编辑此处引文」可增删这组文献，选「查看来源」可核对出处。也可把光标放在引文边缘，按 Shift+F10。阅读模式下单击引文查看，源码模式下直接编辑引用键。

从「正文编辑 → 更多 → 稿件管理」按当前章或全稿搜索附件、公式和已引用文献。附件可按章节查找或按文件去重，详情可打开原图并逐处定位。图表库中的图片可在「文件操作」重命名，未用于当前稿件的图片可移出当前库。公式页默认列独立公式，详情可预览、定位和修改。窄窗通过「返回结果」回到刚才的查找位置。见稿件管理编排。

「正文编辑 → 更多 → 引用样式」同时控制文内引文和文末 References，可选 APA 7、IEEE、Nature、Vancouver / NLM、Chicago 18 作者－年份、MLA 9 和多个 GB/T 7714 样式。「导入自定义 CSL…」接受含文内引文和参考文献两套规则的独立 `.csl` 文件。可以导入期刊提供的样式，也可以用 CSL 编辑器修改规则再导入。样式保存在当前项目并随项目包迁移。带 Zotero 字段的 Word 交接稿在 Zotero 内刷新时，需要在 Zotero 中安装同一自定义样式。

在正文粘贴或拖入 PNG、JPEG、WebP，或右键「图片」从图表库选择原件。插入后在图号后直接写图注。用「图片 → 稿件中的图片 → 交叉引用」插入可跳转的图号，移动图片及图注后，稿内图号和交叉引用随顺序更新。「稿件中的图片」显示每处图片所在章节。旧有的独立 Markdown 图片可以在同一列表选择「自动编号」，迁移时移除图注开头的旧图号并保留说明。源码使用普通 Markdown 图片、图注段落及同文档链接，移动时一起搬动图片行、行尾锚点和图注段落。

在「正文编辑 → 更多 → 正文设置」选择「图 1」「Fig. 1」或「Figure 1」。编号图的图注、交叉引用和导出随当前项目的选择显示。

正文和图表库随滚动按需加载，加载期间保留缩略图位置。点缩略图可查看原图和图注，打开按原图比例留出适量边距，放大可平移查看细节。右键「表格」可插入管道表格。新导入的 Sit 工作稿直接包含图片链接。对仅有文字引用的旧稿，可在「更多 → 补入来源图表的 Markdown 链接」后移动、改写或删除这些链接。导出的 Markdown、Word、PDF 和 LaTeX 带对应版本的图号与图注。带图片的 Markdown 导出为 ZIP，解压后将 manuscript.md 与 figures/ 放在一起。

结构阅读包含「全文结构」「段落卡片」「段内逻辑」三个尺度。工具栏位于项目导航正下方，卡片从工具栏下方滚动。独立的「正文对照」开关打开当前保存稿的只读正文；桌面左右对照、窄窗上下对照；「同步滚动」默认开启，另一侧按共同章节、段落及段间进度跟随。可在正文对照栏取消勾选以独立浏览；重新勾选时，以最后滚动的一侧对齐。该选项按本机项目记住。切换尺度保留当前章节；从全文结构返回细读时仍能接上刚才的段落。可拖动分隔条或用左右键调节宽度；开关、比例和尺度按本机项目记住。点结构原句在对照栏定位，从顶部切回正文编辑时恢复上次写作位置。阅读区提供阅读、批注和询问。

对照正文选择原句后可批注或询问。批注绑定保存稿版本和准确位置；询问只附引用到会话草稿，由作者填写并发送，不自动发消息。批注保存后留在阅读区，不改变稿件或创建正文版本。

「呈现设置」与项目设置中的「结构阅读呈现」共用文字＋符号简图／文字＋可视简图偏好。Ctrl＋上／左、下／右在三个尺度内切换。全文层保留图号入口，下两层按需加载原图；点击图片原位查看，捏合或 Ctrl＋滚轮缩放，双指滑动／按住拖动平移，双击／空白／Esc 关闭。钉住暂不提供。

本轮改动与安装验证见阅读边界记录。历史四尺度记录保留为当时的验收证据，不代表当前导航。

在结构阅读工具栏点「翻译」可译当前章节。要译一小段，打开「正文对照」，选中原文后点「翻译选段」。选择模型并开始后，可按段阅读简体中文译文、展开核对原文。长章超过单次范围时，可分段选择翻译。译文留在阅读弹窗。

默认术语库为 `~/.manuscript/translation-glossary.md`，首次成功翻译后由 AI 根据本次原文建立，DSH 与 Codex 的各项目共用。后续翻译优先沿用库中的译名，仅在有明确依据时新增、修订或移除由 AI 管理的词条。每次可在译文旁查看变更和理由。作者手动填写或修订过的译名优先，AI 不会覆盖。

换电脑前，在「结构阅读 → 翻译 → 本机术语库」选择「导出 Markdown」。到新电脑选择「导入 Markdown」，即可复用词条。已有本机库时合并新增词条，遇到不同译名会保留本机条目并提示冲突。显式设置 `MANUSCRIPT_DATA_DIR` 或旧的 `LUNXU_DATA_DIR` 时，术语库随该路径走。向模型发送的内容包含本次原文及命中的词条。

### 整理整篇稿件的结构

结构阅读的「整理结构」位于呈现设置左侧。点击打开操作面板，选好模型后点「开始」。运行时按钮显示实际进度环和百分比，点击查看阶段、章节／批次、错误和调用详情，并可停止或重来。成功保存后显示「已完成」悬浮提示 1 秒。任务在切页期间继续，重开结构阅读可查看进度。

调用失败会显示具体原因；临时失败或输出校验问题每批最多自动补试一次，连续 3 批调用失败暂停余下任务。明确的额度／认证／上下文拒绝直接暂停；失败、尚未执行和已成功批次分别计数。

「继续 / 更新」复用同模型、同材料、同生成规范的成功批次，并重新汇总全文；更换模型完整重做。「重来」停止当前任务，跳过全部批次缓存，按所选模型重新生成。失败／取消可继续，完整成功前旧结果保留。运行中改稿会标为待更新，不能把旧解读套到新稿上。两种样式共用整理结果，正文、原图、作者写作计划及正式导图不被改写。

work 以正文长度合批，小章节合并请求，DSH 最多两路并发；限流后降为一路。参考文献列表只在正文及正文对照中查阅，三种结构阅读尺度和模型整理均跳过该节。致谢及空标记本地处理；失败仅补未通过的任务或段落，精确原句校验不放宽。已完成章节可看「本轮预览」，可切回上次完整结果；新版生成规范不复用旧规范缓存。调用耗时为各批累计，不等于整轮墙钟时间。

新版整理分别生成短标签、展开说明、原句引用和明确关系：全文看问题与章节主线，段落看任务与承接，段内沿具名箭头横向读，分支另起一行，没有关系的节点不画箭头。点击节点时，说明、原句与图号浮在节点旁，不推移段落；点空白、再点节点或按 Esc 关闭。「在完整正文中定位」可打开正文对照并标出原句。旧结构的长摘要折叠保留；升级后点「整理结构 → 重来」可生成新版模型结构。

### 在项目地图上编辑主题

- 选中主题后用 **Tab** 添加子级，用 **Enter** 添加同级，也可从「新增」菜单点击这两项。中心主题没有同级。
- **左键从空白拖**是框选；**从节点本体拖**是移动。拖进两个同级主题之间的空白处可以插队；拖到另一节点上、下缘可排在它之前或之后，拖到中部可成为它的子主题。右拖或双指平移；静止右击打开菜单。
- 右击节点可**复制、粘贴、剪切、删除**整个分支；「顺序」可不用拖动就上移或下移。**插入 → 图片／链接／LaTeX 公式**可给主题添加内容，再次打开可替换或移除。每种材料每个主题一项；图片原件保存在宿主项目中，支持 PNG、JPEG 和 WebP（≤8 MiB）。图外复制的多行文字也可粘贴为主题，Tab 缩进表示层级。
- **显示 → 适应画布**只改变视野；论文树固定向右，同级从上到下。拖动时卡片跟手，虚线框预告松手位置；Esc 取消。批注框直接插在所点节点里，邻近分支让开；保存的批注留在同一处。详细依据和验收步骤见地图交互规范。

在同一 DSH 窗口里从地图去项目管理，未发送的聊天文字、图片与待附批注按项目及收件人保留。管理页改了正文再切走，会先保存；保存失败停在原编辑框。返修意见可先关闭，下次从「继续填写返修意见」接着写。「确定」才创建记录。临时输入不承诺在关闭宿主后恢复。

### 在项目地图上与主 Agent 构思

1. **在单图标记。** 打开项目地图，点顶部带指针图标的「批注」。点节点或连线，写下想法，点「保存批注」，可连续标多处。再点「批注」或按 Esc 退出；编号和批注卡仍在图上。
2. **把批注附到消息。** 点主 Agent 头像。在聊天框点「添加图上批注（N）」会默认附上全部未发送的批注；展开「批注 · N 条」可以取消勾选，点 × 只从这条消息移除。再输入「先解释」或「按这些批注修改」等指示，发送。没有附上的批注不发送，保留给下一轮。
3. **从回复看差异。** 只有 Agent 实际改动了图，那条回复下才有「查看导图差异」。点击看左侧本轮修改前、右侧本轮建议稿；可继续批注、聊天。从最新回复点「核对全部待写入修改」，左侧是当前项目图，右侧是累计建议稿。核对全部增删改后，点「确认导图」才保存正式版及 Agent 版本说明。「返回单图」回到编辑；「版本历史」可比较已确认的各版。重开项目仍从单图开始，原生聊天里的差异可回看。

### 从两版导图看同一节点当时的正文与批注

在 DSH 的「项目管理 → 版本时间轴」点「手动保存 / 标为重要」，填写如“第一次送阅”的说明。再改稿、批注，保存第二次。即使只改正文、没有改图，也能成对保存。回「项目地图 → 版本历史」，在左右版本框各选一个已保存的版本，分别点同一节点；每侧列出配对的稿件版本、当时关联的正文、正文选区批注和节点／连线批注。确认 Agent 的正式导图也会配对，但讨论或回看本身不保存新稿。

「保存时」固定不变；后来专门给历史图写的「回看留言」单独标明。无正文的节点保持构思状态；旧导图未留配对记录时会明示。可用两版测试项目及实测复查。

### 从卡片原位写到正文

在 DSH 导图中，单击选中章节，点节点「⋯ → 定位正文」进入该节。顶部「正文编辑」回到上次写作位置。提供章节侧栏编辑器的其他入口支持单击章节展开写作区。DSH 的改名、新增和保存操作见[导图操作](#导图正文编辑与结构阅读)。

尚未关联正文的构思节点可点「写这一节」。DSH 顶部「正文编辑」打开连续稿面。用笔／书按钮切换编辑和阅读，从「更多 → 源码模式」编辑源码。源码按稿件类型显示 Markdown 或 LaTeX，阅读模式不修改正文。LaTeX 沿用现有片段编辑。旧原句无法定位时回到对应整节编辑，作者可在 Agent 任务或旧执笔标记仍存在时直接写作。

在全文编辑器右键打开插入菜单，可加入引文、原文片段、图片、表格和公式。键盘可用 Shift+F10，工具栏也有「更多 → 插入…」。「更多」还提供查找替换、讨论全文、Agent 建议和已有写作记录。选中文字后可高亮、批注或询问。

展开「写作思路」，选卡片、调整顺序并写连接理由，填写作者简述。可先点「保存」只留简述，之后再写正文；也可直接写稿。点链条中的卡片可回原图。每次保存写作计划或带计划的正文，都自动保留本版 Markdown 写作记录，可从「更多」下载，也随项目包备份。它包含选用卡片的稳定标识与当时内容、链条、作者简述、Draft 及本版书目。

全文工具栏的「更多」提供稿件管理、引用样式、参考文献与图表、正文设置及导出。把光标放进目标章节，点「更多 → 本章折叠写作」可展开摘句修改原段。单节阅读页保留自己的「资料」「阅读设置」「导出」入口。[稿件管理用法](#正文引文与图片)

选区批注默认保留在项目；在批注列表点「附到主 Agent 讨论」才放入输入框，作者仍需发送。离开编辑器会先保存，失败保留输入；模式切换不产生新稿。试写项目与验收

### 配置支持 Agent 和自建角色

打开项目地图的「团队设置」。现有主、执行、验收、搜证、解释角色保留原身份与会话；新增支持 Agent 和内审 Agent。展开「职责与权限」查看定义，按需固定头像并选择模型。支持 Agent 的职责包含知识与笔记取材、实验记录整理、Draft／视图转换和按 `专业术语库.md` 翻译；这些职责说明不代表外部 MCP、完整转换或双向翻译已验收。

点「创建角色」，选择支持、执行、验收或内审，填写职责、勾选工具、限定可写正文及文件名。角色归属于当前项目，统一交付给主 Agent；类型创建后固定，核心角色不可覆盖。所有角色可读取本项目资料；正文和文件的选择器限定**写入**，不是资料保密隔离。文件名 `*` 表示所有项目文本文件，留空不能写文件。创建／调整失败会保留输入。可点「与主 Agent 核对分工」，把核对请求放入主会话，再由作者发送；服务端的权限冲突检查不依赖模型回答。

在「任务分工」查看或重派 Agent 任务。主 Agent 用 `team_status` 查看分工，再用 `assign_task` 派发；不需要作者先交出正文，也不会自动唤起另一个会话运行。对应角色通过 `deliver_task` 交付，或由工作台运行任务；写作交付保存为候选稿，不直接写入当前正文。验收角色不能改正文，执行者不能独立验收自己；作者采用建议后仍需按要求审查。

停用前重新分派未完任务。旧角色不再获得新的项目工具权限；仅凭记录中的真实旧写作任务身份，允许迟到交稿进入候选档案，不替新角色完成任务。角色定义、任务历史和候选稿随项目备份。外部 MCP 和通用宿主工具仍由 DSH 授权。角色盘点。

### 作者直接编辑，Agent 交稿留作核对

点导图节点、连续稿面或管理页正文即可写作，无需打开团队设置或切换执笔人。即使旧项目仍有“Agent／Word 执笔”标记，也可直接保存；只读历史不变。作者不同窗口同时改稿时仍检查修订号，失败保留正在输入的草稿。

Agent 按指定版本写出的正文统一先存为**待核对候选稿**，包括基线未变的情况，避免碰到作者尚未保存的输入。基线变化、任务重派或原块被移除时，记录对应原因，完整文本和原始交付仍保留；同一回执重试不重复建建议。角色或任务身份不合法的调用仍拒绝，不能借冲突名义越权。

在编辑器或顶栏点「Agent 建议」，选择当前节或项目中的一份建议。可展开 Agent 当时使用的基线，并排查看当前正文和原始候选稿，在「核对稿」中合并、删改。冲突时核对稿默认从当前正文开始，保护作者的新内容；无冲突时默认显示候选稿。点击「保存核对稿」才产生新的正文版本；「暂不采用，保留建议」只标记建议，不删正文或候选。原始交付中的来源记录尚未核验，不会自动变成已确认的证据。

核对期间正文再次改变时，保存会被阻止，合并输入仍保留。点「更新对照」，重新比较后再保存。已采纳和暂不采用的原始候选均能重开、下载，随项目包恢复；原块已删除时只供查看／下载，不自动恢复正文。见DSH 验证与测试项目。

## 稿件怎样流转

在 DSH，已有稿可以直接从正文开始。从零起草可以先写正文，也可以先用导图选卡、排列逻辑链条并保存简述。[稿件流转图](07-manuscript-workflow.md)

| 想做什么 | 怎么做 | 怎样确认结果 |
|---|---|---|
| 从想法起草 | 对尚未关联正文的构思卡点「写这一节」。展开「写作思路」，选卡、排列顺序并写简述，再扩写为段落。 | 重开后能核对链条、简述和选用的卡片。写作记录可下载为 Markdown。 |
| 从已有稿开始 | 将论文导入正文，打开「正文编辑」读写连续稿件。 | 导入内容成为项目章节。作为参考资料上传的附件保存在文献库。 |
| 留下送阅版本 | 在正文右下角点「保存 Draft」。 | 首次得到 Draft 01。继续改工作稿，再次显式保存有变化的内容才得到下一个编号；点击版本号可回看。 |
| 核对稿件结构 | 打开「结构阅读」，选择全文结构、段落卡片或段内逻辑。打开「正文对照」，从结构原句定位到保存稿。需要模型解读时点「整理结构」，选择模型后开始。 | 对照栏显示原文。回到「正文编辑」修改；逐段改写可用「更多 → 本章折叠写作」。 |
| 翻译一段原文 | 在结构阅读的「正文对照」选中原文，点「翻译选段」。 | 译文在弹窗中显示，沿用本机术语库。 |

**规划中的流程。** 每版 Draft 通过一轮 Agent 对话生成图解、核对差异并更新正式思维导图，见需求池中的 FOLD-03。支持 Agent 使用项目专属术语库作双向翻译，是另一项规划。当前的阅读翻译使用本机共享术语库。

两轮稿件样例展示作者想保留的材料。卡片起草已有版本化写作记录，可下载并随项目包恢复；按版生成图解和导图的完整留档仍待实现。

## DSH：思路回看

在 DSH 打开项目 → **项目工具 → 项目信息与设置 → 思路回看（Flash-Jev）→ 开启本项目回看**。只开一次。正文编辑时选中段落点「回看思路」，或直接问项目助手某个想法怎么来的。暂停也在项目设置。
