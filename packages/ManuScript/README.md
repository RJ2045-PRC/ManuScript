# ManuScript 0.13.0 · 首次公开测试版

<img src="assets/logo.svg" width="64" height="64" alt="ManuScript 标志">

ManuScript 是原「论序」的正式新名称。当前插件与工具标识为 `manuscript`。已有项目继续读取原数据目录 `~/.lunxu`；旧项目包和 Word 交接文件也可直接打开。

论文项目按块保存。作者与统筹 Agent 商定框架后，可以逐块搜证、直接写作、核对候选与验收。每个块的目的、论证顺序、原文、批注与意见都有入口。作者始终能直接编辑正文；Agent 后台交付保存为待核对候选，不覆盖当前稿或未保存的输入。写作 Agent 交稿并不等于作者确认。

## 第一次在 DSH 试写

从左栏打开 ManuScript，在项目库新建或打开项目。顶部有「导图」「正文编辑」「结构阅读」三个入口。

1. 在「正文编辑」写一段，等待自动保存。点击右下角「保存 Draft」留下编号快照。之后点版本号可回看，工作稿可继续修改。
2. 在「导图」单击章节选中它，用节点的「⋯ → 定位正文」打开该节。点顶栏「正文编辑」会回到上次停笔的位置。
3. 在「结构阅读」切换全文结构、段落卡片、段内逻辑。打开「正文对照」即可查看保存稿并核对原句。对照栏可批注或询问；编辑正文请回到「正文编辑」。

在正文中选中原句，点「询问」并发送问题，原句会保留高亮。旁注显示问题和从回复中摘取的原话；在对话中选一段回答，点「用作旁注摘录」可替换。旁注可定位对应回复，也可继续追问。问题、摘录和聊天定位都不写进 Markdown。

点击章节图片原位查看，只显示原图及原文图注。捏合或 Ctrl＋滚轮缩放，双指滑动或按住拖动平移，双击图片／空白处／Esc 关闭，返回原阅读位置。暂不提供钉住。导图缩放控件在画布左上悬浮，可收至颜色说明左侧；正文编辑和结构阅读不显示导图底栏。

**work 整篇整理（0.12.4 同号补丁）**：结构阅读的「整理结构」位于呈现设置左侧，点击后选择 DSH 模型，再点开始；选择模型不自动执行。自动准备整篇稿件与图表上下文，按批整理段落任务、短节点、展开说明、精确原句与显式关系，再汇总全文问题和章节主线；运行时显示真实进度环，悬停查看百分比，点击查看已完成章节及调用详情。成功保存后悬浮提示「已完成」1 秒。支持停止、继续／更新、重来；继续复用同模型同材料同规范的成功批次，重来忽略全部缓存，换模型完整重做，新结果完整成功前保留旧解读。短章节合批，DSH 两路并发，限流后降为一路；参考文献列表在正文及正文对照中查阅，三种结构尺度与模型整理均跳过该节。致谢在本地处理。已完成章节可看标注清楚的本轮预览，随时切回上次完整结果。临时失败或输出校验问题只补未通过部分，每任务最多自动补试一次；连续 3 批调用失败暂停剩余任务，明确额度／认证拒绝直接暂停，并显示具体错误与未执行批次数。离开页面后后台继续；重启宿主的中断任务可重试。正文修改会使对应旧结果待更新，整理不改正文／写作计划／正式导图。图片能力明确支持时附可读取原图，否则仅据正文图注，并标明输入边界；结果需作者核对，不代表科研结论已验证。

**本轮改动**：DSH 原生对话在有记录的回复旁显示「查看导图变化」或「对照原段落」。点击在右侧查看本轮新增、移除或更改的节点，或候选稿相对原稿的变化。普通对话不显示入口；查看不会改稿。

**DSH NEXT**：点左栏「ManuScript」进入项目库。可以新建文件夹、打开现有文件夹，或单击旧项目为它选文件夹。DSH 按真实路径创建或复用工作区；同一工作区的每个团队角色绑定一条独立的原生会话。点头像可在地图旁发言，点「在 DSH 中继续」进入原生窗口，再点侧栏「ManuScript」回到原项目与对话。绑定前讨论供展开回看，不会自动送进新会话。首次会话优先使用本项目该成员的模型，其次是主 Agent 的设置，再其次为宿主默认；原生会话中可用 DSH 的模型菜单。文件夹内的建档快照只是当时的稿件，最新正文、证据与版本仍由项目库保存。原生聊天记录由 DSH 管理，导出 ManuScript 项目包不会复制 DSH 会话。

**项目地图的鼠标操作**：按住右键拖动平移；按住右键或 Ctrl 滚动滚轮，以可见画布中心每格缩放 10 个百分点。左键点选主题，左键拖出选框，Shift＋单击增减成员；要移动主题层级，按住节点本体拖动。选中主题后点「添加概要」，在右花括号旁输入文字并回车。概要可双击改写，也可和其他主题再组成一层概要。删除概要保留其成员；批量删除主题会一并移除地图上的子主题，可一次撤销，已有正文块保留。

**原生会话设置**：头像聊天框显示该会话的工作模式、访问权限与 Agent 预设。权限与预设选项来自 DSH；Plan 由当前 Agent 的原生命令切换。DSH 只允许在会话开始前更换 Agent 预设。只读或 Plan 会阻止项目写工具；完全访问不会自动开启。

**Codex**：插件为 `manuscript_workbench` 提供 MCP App 全局入口和会话入口。安装或更新后完整退出并重启 Codex，再从全局导航的「更多 / Explore」打开 ManuScript；宿主显示图钉时可固定到左侧栏。工作台直接在 Codex 原生 MCP App 中运行，项目选择、标签页、正文编辑、版本与返修操作通过 App 私有工具桥接到本机数据，不再跳转 localhost。界面读取宿主明暗主题与标准颜色变量，主题变化时同步更新。项目与正文仍保存在本机。也可以在新会话中说“打开 ManuScript 论文工作台”作为兼容入口。若从本仓库安装，先运行 `codex plugin marketplace add "$PWD"`，再运行 `codex plugin add manuscript@manuscript-lab`。

**版本和返修**：在「版本时间轴」展开普通版本，任意选择两版查看逐字 diff，或向 Agent 请求摘要。在「返修对照」保留返回原件、所针对的旧版原句、当前块和作者决定。先选「修改缘由」可标明某次正文修改由作者、导师或审稿人发起。「送导师」「投稿」是冻结本地 Word/PDF 稿的操作，未连接邮件或投稿网站。

**DSH 原位起草。** 尚未关联正文的构思卡可以点「写这一节」。展开「写作思路」，选卡、排序、写连接理由和作者简述；保存后可下载写作记录。进入连续正文后，用笔／书按钮切换编辑与阅读，通过「更多 → 源码模式」编辑源码。选中文字后可高亮、批注或询问。

**DSH 图稿配对**：在项目管理的版本时间轴手动保存并命名，再到项目地图的版本历史，在左右选择已保存的版本。点同一节点可分别读到当时的正文、正文选区批注与图上批注。没有配对记录的旧导图会说明原因。

**文件**：「文献与经验」可导入参考 PDF、BibTeX、笔记，或从作者已开启本机 API 的 Zotero 选择书目。为需要页码短引的条目另行导入原文 PDF。支持 Word、LaTeX、Markdown 主稿；导出 Word、PDF、Markdown、LaTeX。可从「备份整个项目」下载一份包含不可变原件和所有版本的 ZIP；「恢复项目包」总是另建副本。全新安装的两端项目分别保存在 `~/.manuscript/dsh`、`~/.manuscript/codex`。跨项目经验保存在同一宿主内，不会跨宿主自动同步。

**本机依赖**：开发基线 Node ≥24.9.0、Python ≥3.11（python-docx、pypdf、pdfplumber、lxml）、Pandoc、Poppler（pdftoppm，用于出版原图）、LibreOffice。插件优先使用本机已安装的 Codex 文档运行环境；可用 MANUSCRIPT_PYTHON 指定 Python。安装包含离线 Nature 示例原件。模型功能仍需宿主具备可用的模型连接。在完整源码仓库中，依赖初始化与构建步骤由根目录 README 的「接手开发」入口维护。

验证材料收录在源码仓库的 verification/ManuScript 目录。没有测试扫描件 OCR、任意 Word 样式或复杂多文件 LaTeX 工程的无损往返。

**项目地图与团队**：在 DSH 项目中点顶部「导图」；Codex 工作台提供「项目地图与团队」入口。默认显示主 Agent 和 Teams；团队设置可固定执行、验收、搜证、解释 Agent，逐个指定当前宿主列出的模型。打开头像不触发模型，群聊每次只调用指定的成员。讨论记录关联发言时的主题，地图草图、讨论、模型分工按项目保存在该宿主的数据库，也随整个项目备份。跨宿主恢复副本时需重新选择模型。独立 HTML 预览可看界面，不调用模型。地图草图与正文分别保存；聊天不会自动改稿。

项目工具可读取指定来源、读写项目文本文件、保存基于指定版本的正文候选稿，以及提出待审核地图建议。文件保存在本机 ~/.manuscript/<宿主>/project-files/<项目ID>/，每次修改均保留可下载的版本和回执；覆盖前核对当前内容哈希。正文候选保存基线、真实角色及完整交付；版本变化时仍保留，作者核对后采用。项目包包含文件版本。已有安装的项目文件仍在原数据目录。默认不改任意外部目录。

**辅助阅读：阅读尺、ADHD 阅读显示（词首加粗）与结构色块。** 从单节阅读工具栏的「阅读设置」开启；首次使用默认关闭三项辅助，已有偏好继续保留。分析默认使用「模型 · 上下文」，启用色块时默认「只看色块」。打开阅读页不会调用模型；选择「分析本章」或「分析全文」才逐段调用。DSH 使用该项目解释 Agent 的模型，若未设置则使用主 Agent 的模型；启用跟随时使用主 Agent。没有配置时会提示选择，不会暗中切换为规则结果。

模型读取当前段、前后相邻段的局部上下文和标题。色块标的是句子在本段里的写作作用（如背景／已有报告、证据／支持、拟进行的方法），必须能在当前段唯一定位；指向色块可看判断依据和来源。颜色不核验证据，也不把「拟检验」标成已取得的结果。同一句文献报告在背景段和论证段可以换写作作用，来源不得升格。「本段没提」不虚构引文；指向段旁 ⓘ 查看具体问题和缺少的信息。结果保存在当前阅读环境，按项目、章节、正文版本和新分类区分；旧版四类缓存不会被当成新标注。分析全文会跳过已完成的段落；停止在当前段完成后生效。原文、版本和导出稿不包含这些阅读标记。可随时切换到「规则标注」比较；词首加粗与逐行阅读尺仍可单独开启。

「导入论文」将 Markdown、Word、LaTeX 或有文字层的 PDF 作为新增章节导入当前项目。PDF 按页提取、按版面空行分段，多栏和表格阅读顺序需对照原件；扫描件需要先 OCR。仅作为参考资料上传的附件不会自动变成正文。

**折叠写作**：在正文编辑器把光标放在目标章节，点「更多 → 本章折叠写作」。展开摘句可改正文，保存后更新该章的版本，并从新稿重新摘句。折回或重开时显示本章前后两版的字词差异：新增用底色与下划线，删去用删除线。点「查看带引用的原句」对照证据表述，点「固定原文」打开同一版附件的对应页。可用本机默认 PDF 阅读器打开项目原件副本；若书目关联个人 Zotero 库，可用「在 Zotero 打开第 N 页」定位到相同附件。后者要求本机 Zotero API 可用，且附件内容与固定版本完全一致。这个入口使用 [TextFold](https://github.com/chenxiachan/textfold) 的本地论文摘句，不调用模型、不判断引用是否足以证明新句。上游版本与许可证在 workbench/third_party/textfold/。

**支持与自建角色（0.12.4 同号补丁）**：项目地图的团队设置可创建支持／执行／验收／内审角色，限定项目工具和写入范围；内置支持与内审角色可直接固定。通过「任务分工」查看和重派未完任务。作者不需交接即可编辑，Agent 正文候选从正文旁的「Agent 建议」核对后保存。停用前重派任务；合法迟到写作结果只归档，不替新角色签收。角色和任务随项目备份，DSH 会话保持独立。派工不自动启动下一角色；外部 MCP、完整转换与术语翻译仍需后续验证。项目角色权限与 DSH 沙箱／Plan 叠加，不替代宿主通用工具授权。

## DSH：思路回看

在 DSH 打开项目 → **项目工具 → 项目信息与设置 → 思路回看（Flash-Jev）→ 开启本项目回看**。只开一次。正文编辑时选中段落点「回看思路」，或直接问项目助手某个想法怎么来的。暂停也在项目设置。

## 早期版本记录

以下条目保留当时的菜单名称。当前操作见文首的[DSH 试写步骤](#第一次在-dsh-试写)。

**0.11 写作与证据**：成果页可选择 APA 7、IEEE 或 Nature 样式；源码保留稳定键。文献库可查看本地索引覆盖、切换检索方案、重建索引，或只读同步本机 Zotero 条目的笔记与高亮。在正文选区选择「生成逻辑图」后可编辑节点与有向关系；图表库支持从 PDF 框选出版原图并回到固定版原页。TeX 支持正文片段的原位编辑，未知命令保留在源码；不执行自定义宏。团队设置可让全员跟随主 Agent；原生执行中的文字、工具与待批准事项来自 DSH 会话事件。

**0.5 聊天与项目工具**：输入框上方可以直接选择当前角色的模型。Enter 发送，Shift+Enter 换行，Esc 收起。主 Agent 在需要作者取舍时可以给出带示例、选择后果及三项评分的访谈卡。后台回复有未读数。运行状态来自宿主和项目工具；宿主流式返回普通正文时可以看到部分回复。

**0.6 地图交付**：明确要搭建框架时，主 Agent 使用 build_outline 批量追加可编辑的分层草稿主题和对应正文块。只写文件或输出一段大纲不算地图交付。运行中和完成后会同步画布；作者编辑时按变更字段合并，遇到同一字段冲突会提示。访谈答复关联到节点详情，工具记录、已答题和长回复可展开。构思、已写稿件与作者验收分别保留。

**0.7 正文与论证**：项目地图的「查看成果」支持正文版本编辑和选区批注，Agent 处理期间作者仍能直接编辑和批注；「询问」带版本和原文进入解释 Agent 聊天。地图上已写章节可显示带引文的论证；从「折叠阅读」沿章节、判断展开到原句，两个视图共用节点，全文修改后旧引文仍保留。「提取正文论证」把针对该章的请求带入主 Agent 聊天，由作者发送。参照阅读研究与测试记录见 verification/ManuScript/LPBF-review。

**0.8 论文写作与资料库**：打开「查看成果」，在章节上点「编辑」。Markdown 章节可在可视化编辑、源码和稿面间切换；原生 LaTeX 章节使用源码编辑。编辑器提供公式、章节内查找替换、引文、表格和插图。保留定时保存、手动版本与冲突检查；Agent 任务不阻止作者编辑。参考文献支持书目维护、BibTeX/CSL-JSON 导入、BibTeX 导出、本机 Zotero 选取。正文中点击书目键可看原件或出版页面；从本地检索插入的片段另存页码、原件哈希、位置，替换附件不更换已固定证据。暂不对纯扫描件做 OCR。索引使用 FTS5，安装 NumPy 时另用本地 LSA 主题向量检索，不调用云端 embedding。超过 12,000 个片段使用关键词检索。Word/PDF 包含参考文献与实际图表；带附件的 Markdown/LaTeX 打包交付。DSH 工具参数中断会有限重试，保留已完成操作回执。
